Scope and assumptions

Only the current public CMA-rule model is shown. A flag is a screening outcome, not an independent CMA finding. A non-flag does not prove the merger is harmless.

For a convenience centroid, larger grocery shops can also constrain it. Missing OSM floor area therefore does not automatically exclude a rival. Size is displayed where GEOLYTIX provides it; unknown size remains explicit. Supermarket-centroid testing needs a separate model and is not implemented.

Ownership, product scope and trading status remain imperfect. Core evidence excludes detected conflicts; it does not verify every remaining shop. Display boundaries are simplified, but rival membership comes from the original spatial joins.

Methodology and data sources are available in the app’s Methodology tab.
